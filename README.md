# Suki the Sexy Salmon 🐟

A 2D and 3D mascot development project inspired by Aquinos Sushi Bar's Sexy Salmon nigiri.

## Character design
- Salmon-orange nigiri on white rice
- Short perpendicular avocado fringe that ends on the forehead (does not cross the face)
- Jalapeño slice topped with a single red hot-sauce dot
- Expressive green eyes; black nori arms and legs
- No extra green band on the lower body

## Tech stack
- **2D:** Godot 4 .NET / C# — procedural placeholder, later layered sprites and animation
- **3D:** Blender / Python (`bpy`) — procedural blockout, later detailed meshes and rigging

## Run the 2D starter
Install Godot 4 .NET and compatible .NET SDK. Open `2d-godot/project.godot` and run the scene. This is a simplified code-drawn prototype, not final artwork.

## Run the 3D starter
Open Blender > Scripting, load `3d-blender/suki_blockout.py`, and Run Script. The generated model is a rough blockout, not the polished reference.

See `docs/MILESTONES.md` and the GitHub Issues for next steps. Reference images and layered production artwork are not included yet.
